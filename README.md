# 📊 PhonePe Payment Analytics Dashboard | Power BI

An interactive Power BI dashboard designed to analyze payment transactions, customer behavior, transaction value, service contribution, payment success and usage patterns.

> Note: This is a portfolio analytics project based on a PhonePe-inspired/payment transaction dataset and does not represent official PhonePe company data unless otherwise stated by the dataset source.

---

## 🎯 Project Objective

The objective of this project was to transform transactional payment data into an interactive business intelligence dashboard that helps understand:

- Overall transaction performance
- Transaction value trends
- Customer and user behavior
- Service-wise transaction contribution
- Payment success and failure patterns
- Age-segment contribution
- Weekday vs. holiday usage
- Top users by transaction value

## 📈 Dashboard Analysis

### 1. Transaction Performance

The dashboard tracks transaction activity over time to identify monthly trends and changes in transaction volume.

### 2. Payment Performance

Payment status is analyzed to understand successful and unsuccessful transactions, including failed transactions and other payment outcomes.

### 3. Customer Analysis

The dashboard analyzes:

- Unique users
- Top users by transaction value
- Age-segment contribution

### 4. Service Transaction Value

Transaction value is analyzed across different services such as:

- Loans
- Education
- Money Transfer
- Recharge & Bills

### 5. Usage Behavior

The dashboard compares weekday and holiday transaction activity to understand when users are most active.

---

## 💡 Key Insights

- Loans represent the highest transaction value among the analyzed services.
- Weekday usage contributes significantly more transaction activity than holiday usage.
- The dashboard shows an overall payment success rate of 96%.
- Transaction contribution varies across different age segments.
- A small group of users contributes a significant share of transaction value.
